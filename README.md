# ActivityHub

Platforma do agregowania aktywności użytkowników.

## Moduły

- auth-service — logowanie i autoryzacja (Spring Authorization Server)
- activity-service — CRUD aktywności + integracje zewnętrzne
- search-service — wyszukiwanie pełnotekstowe (Elasticsearch)
- frontend-web — Vue 3 + Vite
- mobile-app — Flutter/Ionic
- infra — docker-compose, konfiguracje, k8s
